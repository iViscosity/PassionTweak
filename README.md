# Passion Tweak
Have you ever wanted to adjust the rate your colonists learn? Well now you can! Passion Tweak allows you to tweak the learning rate of each passion level (no, minor, and major) to fit your liking and playstyle!

Each value can be set to any value between 10% and 1000%. Note that extremely high values may cause issues and is not something that I plan on adding.

Available on the [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=2802989358)!

# Manual Installation
- Head to the [releases](https://github.com/iViscosity/PassionTweak/releases) page and download the latest version.
- Unzip the folder within to your Rimworld Mods folder (create one if it doesn't exist). On Windows, this is usually `C:\Program Files (x86)\Steam\steamapps\common\RimWorld\Mods`.
- Launch the game.
- Enable Passion Tweak in the Mods menu.
- The game will automatically restart.
- Enjoy!

# Default Settings
_These can be changed to your liking from the Mod Settings ingame._
- No Passion: 0.35x -> 1.0x
- Minor Passion: 1.0x -> 1.25x
- Major Passion: 1.5x (unchanged)
